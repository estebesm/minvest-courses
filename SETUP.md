# Настройка с нуля — инструкция для нового человека

Здесь — что установить и какие доступы получить, чтобы собирать обучающие видео так же, как это делается сейчас.
Как устроен сам проект и правила для сцен — в [README.md](README.md).

## Коротко: что из чего состоит

| Что | Зачем | Обязательно? |
|---|---|---|
| Папка проекта `courses` | сам код видео | да |
| Node.js + npm | запуск Remotion (сборка видео из кода) | да |
| Python 3 + ffmpeg | проверка видео и работа со звуком | да |
| Claude Code | агент, который пишет сцены и запускает всё остальное | да |
| Скилл `real-sfx` + папка со звуками | звуковые эффекты в видео | да, видео сдаются со звуком |
| Figma (команда M Invest) | генерация новых 3D-иллюстраций | только если нужны новые картинки |
| Репозиторий `minvest-app` | цвета, логотипы и картинки из приложения | только если нужны новые экраны и картинки приложения |
| Ключ Gemini | озвучка голосом | только когда попросят сделать озвучку |

Минимум, чтобы открыть проект и отрендерить готовые уроки, — первые четыре строки.

## Шаг 1. Базовые программы (macOS)

```bash
brew install node python ffmpeg-full
```

`ffmpeg-full`, а не обычный `ffmpeg`: в обычном нет двух функций, которые нужны скиллу со звуками.
Чтобы система брала именно его, добавьте строку в `~/.zshrc` и откройте терминал заново:

```bash
export PATH="$(brew --prefix ffmpeg-full)/bin:$PATH"
```

Проверка:

```bash
node -v        # 20 или новее (сейчас проект собирается на 24)
python3 -V     # 3.9 или новее
ffmpeg -hide_banner -filters | grep -E "drawtext|rubberband"   # должны найтись обе строки
```

## Шаг 2. Проект

```bash
git clone https://github.com/estebesm/minvest-courses courses
cd courses
npm install
npm run studio          # откроется редактор с предпросмотром в браузере
npm run render:intro    # готовое видео появится в out/intro-lesson.mp4
```

При первом рендере Remotion сам скачает себе браузер — это нормально, займёт минуту-две.

Если рендер прошёл и файл открывается — основа работает.

## Шаг 3. Claude Code

1. Установить: <https://claude.com/claude-code> (есть приложение для Mac и вариант для терминала).
2. Войти в свой аккаунт.
3. Открыть в нём папку `courses`.

Claude читает `README.md` проекта — там правила стиля (минимум текста, белый фон, 3D-иллюстрации, палитра
приложения). Просить его можно обычными словами: «сделай урок про облигации по образцу intro».

## Шаг 4. Звуковые эффекты — скилл `real-sfx`

Скилл — это папка с инструкциями и скриптами, которую Claude подхватывает сам. Звуки он не выдумывает, а берёт
настоящие записи из папки-библиотеки.

1. Распаковать папку скилла в `~/.claude/skills/real-sfx`.
2. Распаковать папку со звуками в любое постоянное место, например `~/sfx-library`.
3. Указать скиллу, где лежат звуки (путь у каждого свой, поэтому файл настроек с чужого компьютера не подойдёт):

```bash
cd ~/.claude/skills/real-sfx
python3 scripts/setup.py init --library main="$HOME/sfx-library" --uisfx --index
python3 scripts/setup.py check
```

В ответе `check` всё должно быть `ok`: ffmpeg, библиотека `main` (26 звуков) и `uisfx` (набор звуков интерфейса,
скачивается сам).

4. Перезапустить Claude Code.

Как потом пользоваться: попросить Claude «добавь звуки в урок intro». Он возьмёт список звуковых моментов из
`scripts/sfx-events.py`, соберёт дорожку и положит её в `public/audio/` — урок подключает её полем `sfx`.

## Шаг 5. Figma — новые 3D-иллюстрации

Нужна только когда готовых картинок в `public/illustrations` не хватает.

1. Принять приглашение в команду **M Invest** и убедиться, что файл по ссылке выше открывается и редактируется.
2. Подключить Figma к Claude Code:

```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

3. В Claude Code набрать `/mcp`, выбрать `figma` и войти в свой аккаунт Figma в открывшемся окне браузера.
4. Проверка: попросить Claude «проверь, под кем я вошёл в Figma».

Важно:

- Генерация картинок тратит **платные кредиты** команды. Большие пачки — только после согласования.
- Промпт и способ убрать белый фон описаны в [assets-src/README.md](assets-src/README.md). Стиль держим единым.
- Оригиналы кладём в `assets-src/illustrations`, версии с прозрачным фоном — в `public/illustrations`.

## Шаг 6. Репозиторий приложения `minvest-app`

Нужен, когда в видео появляется новый экран приложения или новая картинка из него (монеты, логотипы компаний).

```bash
git clone https://gitlab.minvest.kg/frontend/mobile/minvest-app
```

Удобнее положить рядом с `courses` (в одну общую папку). Оттуда берутся:

- цвета и шрифт — `lib/src/shared/style/app_theme.dart`;
- картинки — `assets/images`; в проект они копируются уменьшенными в `public/app`.

Экраны телефона в видео собираются по коду настоящих экранов приложения, а не «по памяти» — поэтому доступ к
репозиторию и нужен.

## Шаг 7. Gemini — озвучка

Нужен только когда попросят сделать озвучку голосом. Сейчас уроки собираются без голоса: время слов для субтитров
оценивается по тексту.

1. Зайти на <https://aistudio.google.com/apikey> под своим Google-аккаунтом и нажать «Create API key».
2. В папке проекта:

```bash
cp .env.example .env
```

3. Открыть `.env` и вписать ключ после `GEMINI_API_KEY=`.

Важно:

- `.env` — личный файл. Он не попадает в git, ключ никому не пересылаем.
- Озвучка платная при больших объёмах — следить за расходом в Google AI Studio.

## Проверка, что всё готово

```bash
npm run typecheck                                              # ошибок нет
npm run qa:intro                                               # видео собралось; «ПУСТО» — 0
python3 ~/.claude/skills/real-sfx/scripts/setup.py check       # всё ok
```

И в Claude Code: `/mcp` показывает `figma` как подключённую.

## Частые проблемы

| Что видно | Что делать |
|---|---|
| `command not found: ffmpeg` или скилл ругается на `drawtext` | не добавлена строка с `PATH` из шага 1; добавить и открыть терминал заново |
| `check` пишет, что в библиотеке 0 звуков | неверный путь к папке со звуками; повторить команду `init` из шага 4 |
| Claude не знает про `real-sfx` | папка лежит не в `~/.claude/skills/real-sfx` или Claude Code не перезапущен |
| Figma: «нет доступа к файлу» | вошли не тем аккаунтом (`/mcp` → выйти и войти снова) или нет приглашения в команду |
| Первый рендер долго висит | скачивается браузер для Remotion, подождать |
| Видео без звука | в уроке не указано поле `sfx` или нет файла в `public/audio` |
